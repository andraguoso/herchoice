# herchoice
Informative portal designed for high school girls who are interested in science olympiads.

## Tools
HTML and Tailwind CSS.

## Features
- Multi-page educational portal with dedicated sections for resources, competitions, and community.
- Science resource directory organized by subject and difficulty.
- Competition directory covering Informatics, Biology, Physics, and Chemistry olympiads.
- Custom visual theme with Tailwind CSS, including typography, colors, and hover interactions.

## Process
First, I wanted this to recreate the original propotype we had presented at the bootcamp's showcase, but later I figured I could improve it and actually implement the intended features. 
Reading the shared Good Design tutorial through the Snowglobe portal gave me really useful insight on what I wanted this project to look like for others.
